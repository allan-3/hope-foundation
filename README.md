# Hope Foundation

Hope Foundation was created to support families facing hardship by focusing on three 
key areas: education, health, and shelter. Every donation and volunteer hour goes 
directly toward helping communities build a better future.

🔗 [Live Demo](https://allan-3.github.io/hope-foundation/)

## About the Project

This is a multi page website built to represent Hope Foundation's mission and give 
visitors a way to learn about the cause, get in touch, and contribute through 
donations.

## Pages
- **Home** : introduction to Hope Foundation and its mission
- **About** : background on the cause and the organization's goals
- **Donate** : information on how to contribute and a form to get started
- **Contact** : a way for visitors to get in touch
- **Login** : access for registered users
- **Signup** : registration for new users

## Features
- Clean, multi page layout with consistent navigation
- Dedicated Donate page with contribution info and a contact form
- Responsive design across pages
- Clear, styled UI built entirely with HTML and CSS

## Built With
- HTML
- CSS

## Running Locally
1. Clone this repo: git clone https://github.com/allan-3/hope-foundation.git

2. Open `index.html` in your browser (or use the Live Server extension in VS Code)

## What I Learned
Practiced building a multi page website with HTML and CSS, structuring consistent 
navigation across pages, designing forms, and organizing a layout around a clear mission.

## Notes
The Login, Signup, and Donate form pages are front-end only at this stage — they don't
